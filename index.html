        About this tool
        
    
          Paste or drop OpenAPI 3.0 / 3.1 or Swagger 2.0 in JSON or YAML (up to 5 MB). Conversion is
          automatic. Nothing is uploaded; only your settings are saved.
        
    
        
    
          Max removes descriptions and examples, shortens schema references, and shares repeated
          definitions. Compact keeps full schema names. Balanced and Readable keep more prose.
        
    
        
    
          Operations, parameter locations, required fields, response codes, authentication, and
          supported schema constraints stay in the output. In dense text, ! means
          required, @ references a schema, $ references a shared
          definition, and [T] means an array.
        
    
        
    
          This is a context summary. Docs metadata, vendor extensions, callbacks, webhooks, and
          response links are omitted. External references remain unresolved and are flagged. JSON
          output is a simplified structure, not an OpenAPI document. Size savings compare UTF-8
          bytes against the original formatting.
